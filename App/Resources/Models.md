# Dropped models

This note sits beside `Models/`, not inside it. Xcode copies that folder into
the app as a whole, so a readme or a placeholder in there would ship with the
game.

Drop a `<asset name>.usdz` file into `Models/`. The names are the `AssetName`
list in `docs/asset-brief.md` (for example `gondola_shelf.usdz`). The app loads
the file instead of the code-built shape at the next build, with no code change.

Every file in `Models/` is generated by `bash Scripts/models.sh` from
`Tools/assetgen/` and checked byte-for-byte in CI — never hand-edit a `.usdz`
or a `.png` there; change the generator and re-run.
