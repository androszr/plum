# Dropped models

Drop a `<asset name>.usdz` file here. The names are the `AssetName` list in
`docs/asset-brief.md` (for example `gondola_shelf.usdz`). The app loads the file
instead of the code-built shape at the next build, with no code change.

Every file here is generated by `bash Scripts/models.sh` from `Tools/assetgen/`
and checked byte-for-byte in CI — never hand-edit a `.usdz` or a `.png` here;
change the generator and re-run.
